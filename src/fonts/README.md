# Fonts

Self-hosted Latin subsets, variable weight, loaded with `font-display: swap` from `src/css/app.css`. No font CDN (ADR 0009).

| File | Family | Role | Source | License |
|---|---|---|---|---|
| `bricolage-grotesque-latin.woff2` | Bricolage Grotesque (variable, 200-800) | Display: page titles, verdicts, big numbers | `@fontsource-variable/bricolage-grotesque` 5.3.0 (npm), from github.com/ateliertriay/bricolage | SIL OFL 1.1, `OFL-bricolage-grotesque.txt` |
| `inter-latin.woff2` | Inter (variable, 400-700) | Interface and reading text | rsms.me/inter | SIL OFL 1.1 |
| `jetbrains-mono-latin.woff2` | JetBrains Mono (variable, 400-700) | Code, numbers in columns, labels | jetbrains.com/lp/mono | SIL OFL 1.1 |

### Changed (speed)
- Views load only when their route opens (`import()` per route in `main.js`, ADR 0008 updated): a fresh `#/` no longer pulls the workspace, runners, codegen or program builders. A navigation token skips a render when the hash changed while the module was loading, every view still returns a cleanup, and a failed import shows "Could not load this page. ### Changed
- The legacy `milestone` field is gone from all problem files, the catalog and the problem format (no view has read it since the essential path replaced the milestones).
- Growth estimate: one slow (or fast) middle size no longer spoils a 4-size measurement. - C# on the remote runner failed on "cannot open the device or file specified: 'NuGet-Migrations'".
